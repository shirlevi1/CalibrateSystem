# Calibrate — Project Management Platform

**Calibrate** is a full-stack project and workflow management platform designed to streamline collaboration between organizations and their clients.

The platform provides a centralized workspace for managing projects, documents, users, permissions, and approval workflows.

## Tech Stack

- **Frontend:** React, JavaScript, Material UI
- **Backend:** Python, Django REST Framework
- **Database:** MySQL
- **Authentication:** JWT (Simple JWT)
- **Integration:** REST APIs, Monday.com CRM

## Key Features

- **Project Dashboard:** Centralized overview of projects, progress, and workflow stages.
- **Role-Based Access:** Dedicated interfaces and permissions for administrators and clients.
- **Workflow Management:** Structured project stages, document reviews, and approval processes.
- **Document Management:** Tracking required documents and their completion status.
- **CRM Integration:** Integration with Monday.com for synchronizing project-related information.
- **Responsive Interface:** User-friendly React interface for different screen sizes.

## Architecture

Calibrate follows a full-stack architecture with a React frontend, a Django REST Framework backend, and MySQL for data persistence.

The system uses REST APIs for communication between frontend and backend, JWT-based authentication, and role-based authorization to protect project information.
